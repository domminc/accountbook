# 가계부 사이트 기획서

> 상태: v1.0 · 작성일: 2026-09-25 · 수정: 2026-09-26 (MVP 1~5단계, 2차·3차 완료)
>
> 참고 시트 두 개를 분석해 기능·데이터 모델·집계 규칙을 시트에 맞췄습니다.
> - 2025 가계부 (디어나 가계부 v8 템플릿): 2025년 11~12월 데이터 (실사용 시작은 2025년 11월, 10월 입력분은 제외)
> - 2026 가계부 (디어나 가계부 v9.0.2 템플릿): 2026년 1~4월 데이터. **구조는 이 최신판을 기준으로 한다.**
> 시트 안의 개인 정보(이름, 금액, 계좌, 일부 개인 카테고리)는 이 문서에 옮기지 않았습니다.

---

## 1. 개요

지금 쓰는 구글 시트 가계부를 웹으로 옮긴다. 시트에서 쓰던 흐름(월별 입력 → 이달의 정리 → 연간 통합)은 그대로 두고, 시트라서 불편했던 점을 없앤다.

### 목표
- 시트의 입력 항목과 자동 계산 결과를 **그대로** 웹에서 볼 수 있다.
- 2025·2026년 시트 데이터를 **연도별 xlsx 업로드**로 옮긴다.
- 모바일에서 거래 1건을 **10초 안에** 입력한다.
- 부부가 **하나의 가계부를 함께** 쓴다.

### 하지 않을 것 (v1 범위 밖)
- 은행·카드사 자동 연동 (오픈뱅킹, 마이데이터)
- 투자 수익률 계산, 세금 신고 지원
- 네이티브 앱 (모바일 웹 + PWA로 대체)

## 2. 참고 시트 분석

### 2.1 탭 구성

| 탭 | 역할 | 웹에서 |
|---|---|---|
| 설정 | 가계부 시작 연·월·일, 대분류(최대 24)·소분류(각 최대 15), 지출방법(최대 10) | 설정 화면 |
| 1 ~ 12 (월별시트) | 월별 거래 입력 + 이달의 정리 | 거래 내역 + 월 대시보드 |
| 통합시트 | 연간 대시보드, 월별 × 소분류 상세표, 월평균 | 연간 리포트 |
| 캘린더 (v9 추가) | 월 선택 → 날짜별 수입·저축·고정지출·비고정지출·예비비 합계, 월 수입·저축·지출(예비비 포함) | 거래 내역 > 달력 |
| 예비비 | 월 가계와 별도로 관리하는 목돈(분류별 입금·지출·잔액) | 예비비 |
| 자산관리 | 부채 / 비유동자산 / 유동자산 월별 기록 → 순자산 | 자산 |
| 대출 관리 (v9 개편) | 대출 목록 + 상환 기록(날짜·대출명·상환원금·이자) → 원금잔액·누적이자 자동 계산 | 자산 > 대출 |
| 카드 관리 · 통장관리 · 결제일 관리 | 금융 정보 목록 | 자산 > 하위 탭 |
| 요약 Data · Budget · 주의 (숨김) | 차트·복구용 내부 계산 | 없음 (서버 집계로 대체) |
| 간단 설명서 · 월별시트 샘플페이지(v8만) | 사용법 안내 | 없음 |

### 2.2 거래 입력 구조 (월별시트)

월별시트에는 입력 표가 두 개 있다.
- **이달의 고정지출 내역** (20행, 대분류가 `고정지출`로 미리 채워짐)
- **이달의 수입 저축 지출 내역** (300행)

| 열 | 항목 | 필수 | 비고 |
|---|---|---|---|
| T | 날짜 | ✔ | 가계부 월 기간 안의 날짜만 입력 가능 |
| U | 내용 | | 메모 |
| V | 금액 | ✔ | 항상 양수 |
| W | 대분류 | ✔ | 설정의 대분류 목록 |
| X | 소분류 | ✔ | 선택한 대분류의 소분류 목록 |
| Y | 지출 방법 | | 설정의 지출방법 목록 (현재 `체크카드`, `현금`) |
| Z | 태그 | | 월별시트 태그 목록 (2026 시트: `돌발지출`, `지식`, `투자`, `과소비`) |

**거래 유형은 대분류로 정해진다.** `수입`이면 수입, `저축`이면 저축, 나머지는 모두 지출이다. 지출 중 `고정지출` 대분류만 고정지출이고, 나머지는 비고정지출이다.

### 2.3 월별시트 자동 계산 항목

| 영역 | 내용 |
|---|---|
| 이달의 정리 | 총 수입, 총 지출, 총 저축, 저축률 |
| 무지출 Day | 월 달력에서 고정지출을 뺀 지출이 없는 날 표시 (오늘까지만) |
| 결제 수단별 | 지출방법별 지출 합계 |
| 태그별 금액 | 태그별 합계 |
| 이달의 이벤트 | 날짜·예산·내용 메모 (직접 입력). 2026 시트에서는 이월 금액, 남은 금액(수입 − 지출), 태그 합계 같은 메모용 계산 칸으로 쓰고 있음 |
| 목표 관리 | 수입·저축·지출 목표(직접 입력) 대비 달성률, 소분류별 합계 |
| 주간별 고정지출 / 비고정지출 | 대분류별 월 예산(직접 입력), 소분류별 1~6주차 합계 |
| 차트 | 저축·지출 대분류별 비중 (2% 이하는 `기타`로 합침) |

### 2.4 시트의 불편한 점 → 웹에서 해결

| 시트의 불편함 | 웹에서 |
|---|---|
| 필수 항목이 하나라도 비면 **집계에서 조용히 빠짐** (예: 날짜·금액만 입력한 행) | 저장 전에 검증. 가져온 미분류 건은 "분류 필요" 목록으로 모아 보여줌 |
| 행 삽입·삭제 금지, "값만 붙여넣기" 필수 | 일반 입력·수정·삭제 |
| 카테고리 변경 후 "업데이트"·"Restore" 버튼, PC에서만 설정 가능 | 설정 변경이 바로 반영, 모바일에서도 설정 가능 |
| 대분류 24 / 소분류 15 / 지출방법 10 / 태그 10개 제한, 행 수 제한 | 제한 없음 (화면 표시는 정렬 순서 기준) |
| 해마다 파일 사본을 새로 만들어야 함 | 연도 구분 없이 계속 사용, 연도별로 조회 |
| 부부 공유 시 구글 시트 권한을 따로 설정 | 초대 링크로 배우자 추가 |

## 3. 핵심 개념

| 용어 | 정의 |
|---|---|
| 거래 유형 | 수입 / 저축 / 지출. 대분류의 종류로 정해진다. |
| 대분류 종류 | `income`(수입), `saving`(저축), `fixed_expense`(고정지출), `variable_expense`(비고정지출) |
| 가계부 월 | 달력 월(1일 ~ 말일). 시작일은 1일로 고정한다. |
| 지출방법 | 체크카드, 현금 등 결제 수단. 지출 거래에만 집계한다. |
| 태그 | 거래에 붙이는 표시 (예: 과소비, 돌발지출). 모든 유형에 붙일 수 있다. |
| 예비비 | 월 생활비와 따로 관리하는 목돈. 분류별로 입금(또는 예산)과 지출을 기록한다. |

## 4. 기능

### MVP (1차)
1. **거래 입력/수정/삭제**
   - 필드: 날짜, 내용, 금액, 대분류, 소분류, 지출방법, 태그
   - 고정지출 빠른 입력: 지난달 고정지출을 체크해서 이번 달로 복사
   - 최근 사용 소분류·지출방법 추천, 직전 입력 복제
2. **거래 내역**: 월 단위 리스트 + 달력, 대분류·소분류·지출방법·태그·입력자 필터, 내용 검색
3. **이달의 정리 (월 대시보드)**: 시트 2.3의 모든 항목
   - 총 수입·지출·저축·저축률, 목표 달성률 3개
   - 대분류별 예산 대비 실적, 지출 비중 차트
   - 무지출 달력, 결제 수단별·태그별 합계, 이달의 이벤트
4. **예산·목표**: 대분류별 월 예산, 수입·저축·지출 목표, 주간별 소분류 표. "지난달 예산 복사" 지원
5. **연간 리포트 (통합시트)**: 연간 총 수입·저축·지출, 월별 × 소분류 상세표, 예비비 월별 상세표(분류 × 월), 월평균, 월별 추이 차트
6. **예비비**: 분류별 입금(또는 예산)·지출·잔액, 입금 내역, 지출 내역. 시트와 똑같이 연간 총 지출에 합산 (연간 리포트 숫자를 시트와 맞추려면 필요해서 MVP로 올림)
7. **설정**: 대분류·소분류, 지출방법, 태그 관리 (추가·수정·숨김·순서 변경)
   - 시트 스크립트의 검사 규칙을 따른다: `수입`·`저축`·`고정지출` 대분류는 항상 있고 삭제·이름 변경 불가, 대분류 이름 중복 불가, 같은 대분류 안 소분류 이름 중복 불가, 대분류마다 소분류 1개 이상
   - 시트는 카테고리를 바꾼 뒤 "업데이트" 버튼으로 표를 다시 만들었지만, 웹은 저장 즉시 반영
8. **시트 가져오기**: 참고 시트 xlsx를 올리면 설정·거래·예산·목표·이벤트·예비비를 한 번에 가져옴 ([8장](#8-시트-가져오기)). 전체 데이터 xlsx/CSV 내보내기
9. **가구 공유 (부부 2인)**: 초대 링크로 배우자 추가, 거래마다 입력자 기록
10. **로그인**: 구글, 카카오 (이메일 로그인은 2차)

### 2차 (완료)
- ~~이메일 로그인~~: 아이디·비밀번호 로그인으로 대체
- **결제일 관리 → 반복 거래**: 내용·구분(소분류)·금액·결제일·지출방법을 등록하면, 그 달 상태(예정·오늘·지남·입력함)를 보여주고 골라서 한 번에 거래로 입력. 대시보드에 결제 예정 알림
- **자산관리**: 부채·비유동자산·유동자산 항목을 월별로 기록, 순자산 월별 막대, 지난달 금액 가져오기, 시트 기본 항목으로 시작
- **대출 관리**(상환 기록 → 원금잔액·누적이자 자동 계산), **카드·통장 관리** 목록 (계좌번호는 끝 4자리만)
- 참고 시트의 이 탭들에는 템플릿 예시만 있어 가져오기는 만들지 않음
- **카드 예산 ↔ 지출 연결**: 카드마다 지출방법 하나를 연결하면, 그 지출방법으로 입력한 이번 달 지출(고정·비고정, 결제 수단별 지출과 같은 기준)을 매월 카드값 예산과 비교해 카드 관리·이달의 정리에 보여준다. 한 지출방법은 카드 하나에만 연결 (두 카드에 겹쳐 잡히지 않게). 카드사 청구 기간(전월 1일~말일 등)이 아니라 가계부 달 기준
- **오프라인 입력**: 서비스 워커가 로그인한 동안 거래 입력 화면과 그 화면의 정적 파일을 받아 둔다. 연결이 없으면 어느 화면을 열어도 입력 화면으로 열리고, 저장한 거래는 기기(localStorage)에 사람별로 모아 두었다가 연결되면 자동으로 올린다. 거래 id를 기기에서 정해 보내므로 같은 거래를 다시 올려도 한 번만 저장된다. 서버가 거절한 거래는 사유와 함께 남겨 다시 시도·지우기. 로그인 화면으로 가면(로그아웃·세션 만료) 받아 둔 화면을 지운다

### 3차 (완료)
- **카드 문자·알림 붙여넣기 입력** (거래 입력 > 카드 문자로 입력): 여러 건을 한 번에 붙여 넣으면 카드사별 승인 문자에서 금액·날짜·시각·가맹점·카드사·할부·취소를 읽는다. 누적·잔액 금액은 빼고, 연도는 오늘보다 뒤 날짜면 작년으로 본다. 지출방법은 카드 관리에서 연결한 카드 → 이름에 카드사가 든 지출방법 → 그 가맹점에 지난번에 쓴 것 순서, 소분류는 그 가맹점에 지난번에 고른 것. 취소 문자·원화 금액 없음·같은 날 같은 금액(중복 의심)은 빼 두고 이유를 보여준다. 확인·수정 후 한 번에 저장
- **과소비 알림** (이달의 정리): 소분류·태그별 매월 한도(목표·예산 화면)를 80% 넘으면 주의, 넘으면 초과. 한도가 없는 항목은 지난 3개월 평균(거래가 있는 달만, 두 달 이상 기록이 있을 때)보다 1.3배 이상이면서 1만 원 이상 더 쓰면 "평소보다 많음". 지출만 센다
- **영수증 사진**: 거래 입력 때 붙이거나 거래 수정 화면에서 추가·삭제 (거래당 5장). 브라우저에서 긴 변 1600px JPEG로 줄여(700KB 넘으면 더 줄임) DB에 저장, 서버는 파일 앞 바이트로 JPEG·PNG·WebP만 받는다. 같은 가계부 구성원만 볼 수 있고 거래를 지우면 같이 지운다. Supabase 무료 DB(500MB)에 수천 장 정도 들어간다

```
/settings
  ├─ categories       대분류·소분류
  ├─ payment-methods  지출방법
  ├─ tags             태그
  ├─ members          가구 멤버
  └─ data             가져오기 / 내보내기
```

### 주요 화면

**이달의 정리** (시트 월별시트 왼쪽 영역)
- 상단: 월 선택(◀ 2025.12 ▶, 기간 `12/1 ~ 12/31` 표시)
- 요약 카드: 총 수입 / 총 지출 / 총 저축 / 저축률 / 남은 금액(수입 − 지출) (전월 대비 증감). 남은 금액은 시트의 이벤트 칸에 직접 계산해 쓰던 값
- 목표 달성률 바 3개: 수입·저축·지출
- 대분류별 예산 진행 바 (80% 주의, 100% 초과 색상 구분)
- 저축·지출 비중 도넛 (2% 이하는 기타)
- 무지출 달력: 오늘까지의 날 중 비고정지출이 없는 날 색 표시(`무지출 Day`), 이달의 무지출 일수
- 결제 수단별 · 태그별 합계 표
- 이달의 이벤트 목록

**거래 내역** (시트 월별시트 오른쪽 입력 표)
- 리스트: 날짜별 그룹, 일별 소계, 고정지출은 아이콘으로 구분
- 달력 (시트 캘린더 탭): 날짜 칸마다 수입·저축·고정지출·비고정지출·예비비 합계, 상단에 월 수입·월 저축·월 지출(예비비 포함)
- 입력: 모바일은 하단 `+` 버튼 → 바텀시트(유형 탭 수입/저축/지출 → 대분류 → 소분류 순 칩 선택), 데스크톱은 표 상단 인라인 입력 행
- "분류 필요" 배지: 대분류·소분류가 비어 있는 가져온 거래

**연간 리포트** (시트 통합시트)
- 연간 총 수입 / 총 저축 / 총 지출(월 지출 + 예비비 지출)
- 월별 수입·저축·지출 추이 막대
- 수입·저축·지출 월별 상세표: 행 = 대분류 > 소분류, 열 = 1~12월 + 합계 + 월평균
- 지출 상세표 마지막 줄: 총 지출(고정지출 + 비고정지출)
- 예비비 월별 상세표: 행 = 예비비 분류, 열 = 1~12월 + 합계 + 월평균, 마지막 줄 총 예비비

## 7. 집계 규칙

시트 수식을 옮긴 것이다. 집계 함수는 단위 테스트로 시트 계산값과 맞춰 본다.

| 항목 | 규칙 |
|---|---|
| 월 기간 | 그 달 1일 ~ 말일 |
| 총 수입 | 기간 안, 대분류 종류 `income` 금액 합 |
| 총 저축 | 기간 안, `saving` 금액 합 |
| 총 지출 | 기간 안, `fixed_expense` + `variable_expense` 금액 합 |
| 저축률 | 총 저축 ÷ 총 수입 (수입 0이면 표시 안 함) |
| 목표 달성률 | 유형별 실적 ÷ 목표 (목표 0이면 "목표 없음") |
| 결제 수단별 | 지출 거래만, 지출방법별 합 |
| 태그별 | 모든 유형, 태그별 합 |
| 무지출 Day | 오늘 이전(오늘 포함) 날짜 중 `variable_expense` 거래가 없는 날. 미래 날짜는 표시 안 함 |
| 주간 구분 | 월요일 시작 달력 주. 기간의 첫 주 = 1주차, 최대 6주차 |
| 지출 비중 차트 | 저축·지출 대분류별 금액 ÷ (총 지출 + 총 저축). 2% 이하는 `기타`로 합침 |
| 연간 월평균 | 연간 합 ÷ 경과한 월 수 (연도가 끝나면 12) |
| 연간 총 지출 | 월 지출 합 + 예비비 지출 합 (시트와 동일). 월 대시보드 총 지출에는 예비비를 넣지 않음 |
| 예비비 분류별 | 입금 = 그 해 해당 분류 입금 합, 지출 = 그 해 해당 분류 지출 합, 잔액 = 입금 − 지출 (음수면 0, 시트와 동일). 시트는 파일이 연도별이라, 웹은 연도를 골라 그 해 내역으로 계산한다 |
| 예비비 총계 | 총 입금 = 그 해 입금 합, 총 지출 = 그 해 지출 합, 총 잔액 = 총 입금 − 총 지출 (음수 가능. 분류별 잔액처럼 0으로 막지 않음, 시트와 동일) |
| 캘린더 날짜 칸 | 그날의 수입 / 저축 / 고정지출 / 비고정지출 / 예비비 지출 합 |
| 캘린더 월 합계 | 월 수입, 월 저축, 월 지출 = 고정지출 + 비고정지출 + 예비비 지출. **이달의 정리 총 지출(예비비 제외)과 다름**, 시트와 동일 |
| 대출 | 원금잔액 = 대출원금 − 상환원금 합, 누적이자 = 이자 합. 총 대출 원금·총 원금 잔액·총 누적 이자 |
| 순자산 | (비유동자산 + 유동자산) − 부채, 월별 |

## 8. 시트 가져오기

참고 시트 구조 전용 xlsx 가져오기를 만든다. 브라우저에서 SheetJS로 읽고, 미리보기에서 확인한 뒤 저장한다.

| 시트 위치 | 가져올 곳 |
|---|---|
| `설정` C3 · E3 · G3 | 가계부 시작 연·월·일. 월별시트 N번 = 시작 월 + (N−1). 시작일이 1일이 아니면 가져오기 전에 경고 |
| `설정` B6:B29 / C6:Q29 | 대분류 / 소분류. 종류는 이름으로 정함 (`수입`→income, `저축`→saving, `고정지출`→fixed_expense, 나머지→variable_expense) |
| `설정` C2:L2 | 지출방법 |
| 월별시트 E15:E24 | 태그 |
| 월별시트 T:Z 7~26행, 30~329행 | 거래 (날짜·내용·금액·대분류·소분류·지출방법·태그) |
| 월별시트 "주간별 고정지출/비고정지출" 표의 C 열 | 대분류별 예산 |
| 월별시트 "목표 관리" 표의 C 열 / J 열 | 수입·저축·지출 목표 / 세부 목표 메모 |
| 월별시트 H16:J | 이달의 이벤트 |
| `예비비` B10:C21, B26:E, K10:O | 예비비 분류, 입금 내역, 지출 내역 |
| `자산관리` D11:P38 | 자산 항목과 월별 금액 (2차) |
| `대출 관리` (v9) 8~17행 / 상환 기록 21행부터 | 대출 목록 / 상환 기록 (2차). v8은 목록만 4행부터 |
| `카드 관리` · `통장관리` · `결제일 관리` 4행부터 | 각 목록 (2차) |

**가져오기 규칙**
- **행 위치는 고정이 아니다.** 시트 스크립트가 설정의 소분류 개수에 맞춰 목표·예산 표를 다시 만들고, "고정지출표 추가"로 고정지출 입력 칸이 늘어날 수 있다. 그래서 셀 주소 대신 표 제목(`목표 관리`, `주간별 고정지출`, `이달의 수입 저축 지출 내역`)과 머리글(`No`, `* 날짜`)을 찾아 읽는다. 위 표의 행 번호는 현재 파일 기준 예시다.
- 파일 하나 = 1년치. 연도는 `설정` C3에서 읽는다. 2025(v8)·2026(v9) 두 파일 모두 월별시트 입력 열(T:Z)이 같아 같은 가져오기로 처리하고, 버전별로 다른 탭(대출 관리)만 분기한다.
- 카테고리는 연도별로 조금 다르다 (예: 2026년 고정지출에 소분류 추가). 이름이 같으면 합치고, 새 이름은 추가한다.
- 날짜·금액이 없는 행은 건너뛴다.
- 대분류·소분류가 없는 행은 미분류로 저장하고 "분류 필요" 목록에 올린다. 시트에서는 집계에서 빠지던 건이다.
- **가져오기 시작 시점은 2025년 11월 1일**이다. 그 전 날짜의 거래(2025년 10월 입력분)는 가져오지 않는다. 가져오기 화면에 "시작일 이전 N건 제외"로 표시한다.
- 이 기준으로 가져올 거래(2025년 11~12월, 2026년 1~4월)는 모두 분류돼 있어, 분류 단계 없이 가져온다.
- 설정에 없는 소분류·지출방법·태그가 나오면 자동으로 추가하고 미리보기에 표시한다.
- 같은 연도 파일을 다시 올리면 그 연도의 이전 가져오기 배치를 지우고 새로 넣을지 묻는다. 웹에서 직접 입력한 거래는 지우지 않는다.
- 원본 xlsx 파일은 서버에 저장하지 않는다.

## 9. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | 화면·API를 한 저장소에서 관리, Vercel 배포가 간단함 |
| UI | Tailwind CSS + shadcn/ui | 모바일 바텀시트·칩 선택·표를 빠르게 구성 |
| DB | PostgreSQL (Supabase 등) | 앱 서버가 직접 접속. 요청마다 사용자 권한을 설정해 Row Level Security로 가구 단위 데이터 격리 |
| 로그인 | 아이디·비밀번호 (scrypt 해시, 서명 쿠키 세션) | 외부 설정 없이 바로 사용. 구글·카카오(Supabase Auth) 코드는 보관 중 |
| 집계 | PostgreSQL 뷰/함수 + TypeScript 순수 함수 | 기간·주차 계산은 TS 함수로 두고 테스트 |
| 차트 | Recharts | 도넛·막대·추이 차트 |
| xlsx | SheetJS | 브라우저에서 시트 읽기, 내보내기 |
| 폼·검증 | React Hook Form + Zod | 입력 폼과 가져오기 검증 스키마 공유 |
| 배포 | Vercel + Supabase 무료 플랜 | 가족 규모 사용량은 무료 범위 안 |
| 테스트 | Vitest (집계·가져오기), Playwright (입력 흐름) | 참고 시트 계산값을 기대값으로 사용 |

**보안**
- 모든 테이블에 `household_id` 기준 RLS를 적용해, 본인이 속한 가구 데이터만 읽고 쓰게 한다.
- 계좌번호는 끝 4자리만 저장한다.
- 참고 시트 원본은 저장소에 커밋하지 않는다 (개인 금융 정보).

| 2. 거래 | 2주 | 설정(카테고리·지출방법·태그), 거래 입력/조회 | 완료. 거래 달력 보기는 3단계로 이동 (날짜별 집계와 함께) |
| 3. 이달의 정리 | 1.5주 | 월 대시보드, 예산·목표, 주간별 표, 거래 달력, 집계 테스트 | 완료 |
| 4. 예비비·가져오기·연간 | 2.5주 | 예비비, xlsx 가져오기, 연간 리포트, 2025·2026 데이터로 시트 계산값 검증 | 완료. 실제 2025·2026 시트를 가져와 월별·연간·결제수단·태그·예비비 합계가 시트와 모두 일치함을 확인 |
| 5. 공유·마무리 | 1주 | 가구 초대, 모바일 다듬기, 배포 | 완료. 초대 링크(7일·1회), 홈 화면 추가(manifest·아이콘), 배포 안내 docs/DEPLOY.md. 실제 배포는 사용자 계정에서 |

MVP까지 약 **9주**. 이후 2차(결제일 관리 → 자산·대출·카드·통장, 카드 예산 연결, 오프라인 입력)와 3차(카드 문자 붙여넣기, 과소비 알림, 영수증 사진) 모두 완료.

## 11. 결정 사항

| # | 항목 | 결정 |
|---|---|---|
| 1 | 사용 인원 | 부부 2인이 한 가계부를 공유 |
| 2 | 로그인 | 당분간 아이디·비밀번호로 간단하게. 구글·카카오 로그인 코드는 보관해 두고 나중에 연결 |
| 3 | 가계부 시작일 | 1일 고정 (달력 월). 시작일 설정 기능은 만들지 않음 |
| 4 | 2025년 10월 데이터 | 가져오지 않음. 실사용은 2025년 11월부터 |
| 5 | 예비비 | 시트와 똑같이: 연간 총 지출에 합산, 월 대시보드에는 제외, 잔액 음수는 0 |
| 6 | 이체 | 시트에 없으므로 v1에서 만들지 않음 |

### 시트 Apps Script (code.gs, add_on.gs) 분석 결과
사용자가 전달한 2026 시트의 스크립트는 **템플릿 제공 스크립트(디어나 가계부 매크로 v9.0.x)**이며, 거래를 자동 분류하는 코드는 없다. 하는 일과 웹 대응은 다음과 같다.

| 스크립트 기능 | 웹에서 |
|---|---|
| 업데이트: 설정의 대분류·소분류로 월별시트 목표·예산 표와 통합시트 상세표를 다시 생성 | 필요 없음. 화면이 카테고리 데이터로 바로 그려짐 |
| 카테고리 검사 (`수입`·`저축`·`고정지출` 필수, 중복·빈칸 금지) | 설정 화면 검증 규칙으로 옮김 (4장 7번) |
| 목표·세부 목표·예산을 숨김 `Budget` 시트에 보관했다가 복원 | `goals`·`budgets` 테이블 |
| 복구: 드롭다운·조건부 서식(날짜가 달 밖이면 빨간색, 목록에 없는 대분류·소분류·지출방법·태그 빨간색) 다시 걸기 | 입력 폼 검증. 잘못된 값은 저장 자체가 안 됨 |
| 캘린더 수식·무지출 Day 표시(오늘까지만) | 7장 집계 규칙에 반영 |
| 통합시트 예비비 상세표 생성 | 연간 리포트에 반영 |
| 고정지출표 칸 추가 | 필요 없음 (행 수 제한 없음) |

### 남은 확인 사항
- 없음. 기획 확정 후 1단계(기반)부터 시작할 수 있다.
