# 가계부 사이트 기획서

> 상태: v0.3 · 작성일: 2026-09-25 · 수정: 2026-09-25 (결정 사항 반영)
>
> 참고 시트(2025 가계부 xlsx, 디어나 가계부 v8 템플릿 기반)를 분석해 기능·데이터 모델·집계 규칙을 시트에 맞췄습니다.
> 시트 안의 개인 정보(이름, 금액, 계좌, 일부 개인 카테고리)는 이 문서에 옮기지 않았습니다.

---

## 1. 개요

지금 쓰는 구글 시트 가계부를 웹으로 옮긴다. 시트에서 쓰던 흐름(월별 입력 → 이달의 정리 → 연간 통합)은 그대로 두고, 시트라서 불편했던 점을 없앤다.

### 목표
- 시트의 입력 항목과 자동 계산 결과를 **그대로** 웹에서 볼 수 있다.
- 2025년 시트 데이터를 **xlsx 업로드 한 번으로** 옮긴다.
- 모바일에서 거래 1건을 **10초 안에** 입력한다.
- 부부가 **하나의 가계부를 함께** 쓴다.

### 하지 않을 것 (v1 범위 밖)
- 은행·카드사 자동 연동 (오픈뱅킹, 마이데이터)
- 투자 수익률 계산, 세금 신고 지원
- 네이티브 앱 (모바일 웹 + PWA로 대체)

## 2. 참고 시트 분석

### 2.1 탭 구성

| 탭 | 역할 | 웹에서 |
|---|---|---|
| 설정 | 가계부 시작 연·월·일, 대분류(최대 24)·소분류(각 최대 15), 지출방법(최대 10) | 설정 화면 |
| 1 ~ 12 (월별시트) | 월별 거래 입력 + 이달의 정리 | 거래 내역 + 월 대시보드 |
| 통합시트 | 연간 대시보드, 월별 × 소분류 상세표, 월평균 | 연간 리포트 |
| 예비비 | 월 가계와 별도로 관리하는 목돈(분류별 입금·지출·잔액) | 예비비 |
| 자산관리 | 부채 / 비유동자산 / 유동자산 월별 기록 → 순자산 | 자산 |
| 대출 관리 · 카드 관리 · 통장관리 · 결제일 관리 | 금융 정보 목록 | 자산 > 하위 탭 |
| 요약 Data · Budget · 주의 (숨김) | 차트·복구용 내부 계산 | 없음 (서버 집계로 대체) |
| 간단 설명서 · 월별시트 샘플페이지 | 사용법 안내 | 없음 |

### 2.2 거래 입력 구조 (월별시트)

월별시트에는 입력 표가 두 개 있다.
- **이달의 고정지출 내역** (20행, 대분류가 `고정지출`로 미리 채워짐)
- **이달의 수입 저축 지출 내역** (300행)

| 열 | 항목 | 필수 | 비고 |
|---|---|---|---|
| T | 날짜 | ✔ | 가계부 월 기간 안의 날짜만 입력 가능 |
| U | 내용 | | 메모 |
| V | 금액 | ✔ | 항상 양수 |
| W | 대분류 | ✔ | 설정의 대분류 목록 |
| X | 소분류 | ✔ | 선택한 대분류의 소분류 목록 |
| Y | 지출 방법 | | 설정의 지출방법 목록 (현재 `체크카드`, `현금`) |
| Z | 태그 | | 월별시트 태그 목록 (현재 `반성`, `확인필요`, `돌발지출`, `과소비`, `투자`, `지식`) |

**거래 유형은 대분류로 정해진다.** `수입`이면 수입, `저축`이면 저축, 나머지는 모두 지출이다. 지출 중 `고정지출` 대분류만 고정지출이고, 나머지는 비고정지출이다.

### 2.3 월별시트 자동 계산 항목

| 영역 | 내용 |
|---|---|
| 이달의 정리 | 총 수입, 총 지출, 총 저축, 저축률 |
| 무지출 Day | 월 달력에서 고정지출을 뺀 지출이 없는 날 표시 |
| 결제 수단별 | 지출방법별 지출 합계 |
| 태그별 금액 | 태그별 합계 |
| 이달의 이벤트 | 날짜·예산·내용 메모 (직접 입력) |
| 목표 관리 | 수입·저축·지출 목표(직접 입력) 대비 달성률, 소분류별 합계 |
| 주간별 고정지출 / 비고정지출 | 대분류별 월 예산(직접 입력), 소분류별 1~6주차 합계 |
| 차트 | 저축·지출 대분류별 비중 (2% 이하는 `기타`로 합침) |

### 2.4 시트의 불편한 점 → 웹에서 해결

| 시트의 불편함 | 웹에서 |
|---|---|
| 필수 항목이 하나라도 비면 **집계에서 조용히 빠짐** (예: 10월 46건은 날짜·금액만 있어 집계 안 됨) | 저장 전에 검증. 가져온 미분류 건은 "분류 필요" 목록으로 모아 보여줌 |
| 행 삽입·삭제 금지, "값만 붙여넣기" 필수 | 일반 입력·수정·삭제 |
| 카테고리 변경 후 "업데이트"·"Restore" 버튼, PC에서만 설정 가능 | 설정 변경이 바로 반영, 모바일에서도 설정 가능 |
| 대분류 24 / 소분류 15 / 지출방법 10 / 태그 10개 제한, 행 수 제한 | 제한 없음 (화면 표시는 정렬 순서 기준) |
| 해마다 파일 사본을 새로 만들어야 함 | 연도 구분 없이 계속 사용, 연도별로 조회 |
| 부부 공유 시 구글 시트 권한을 따로 설정 | 초대 링크로 배우자 추가 |

## 3. 핵심 개념

| 용어 | 정의 |
|---|---|
| 거래 유형 | 수입 / 저축 / 지출. 대분류의 종류로 정해진다. |
| 대분류 종류 | `income`(수입), `saving`(저축), `fixed_expense`(고정지출), `variable_expense`(비고정지출) |
| 가계부 월 | 달력 월(1일 ~ 말일). 시작일은 1일로 고정한다. |
| 지출방법 | 체크카드, 현금 등 결제 수단. 지출 거래에만 집계한다. |
| 태그 | 거래에 붙이는 표시 (예: 과소비, 돌발지출). 모든 유형에 붙일 수 있다. |
| 예비비 | 월 생활비와 따로 관리하는 목돈. 분류별로 입금(또는 예산)과 지출을 기록한다. |

## 4. 기능

### MVP (1차)
1. **거래 입력/수정/삭제**
   - 필드: 날짜, 내용, 금액, 대분류, 소분류, 지출방법, 태그
   - 고정지출 빠른 입력: 지난달 고정지출을 체크해서 이번 달로 복사
   - 최근 사용 소분류·지출방법 추천, 직전 입력 복제
2. **거래 내역**: 월 단위 리스트 + 달력, 대분류·소분류·지출방법·태그·입력자 필터, 내용 검색
3. **이달의 정리 (월 대시보드)**: 시트 2.3의 모든 항목
   - 총 수입·지출·저축·저축률, 목표 달성률 3개
   - 대분류별 예산 대비 실적, 지출 비중 차트
   - 무지출 달력, 결제 수단별·태그별 합계, 이달의 이벤트
4. **예산·목표**: 대분류별 월 예산, 수입·저축·지출 목표, 주간별 소분류 표. "지난달 예산 복사" 지원
5. **연간 리포트 (통합시트)**: 연간 총 수입·저축·지출, 월별 × 소분류 상세표, 월평균, 월별 추이 차트
6. **예비비**: 분류별 입금(또는 예산)·지출·잔액, 입금 내역, 지출 내역. 시트와 똑같이 연간 총 지출에 합산 (연간 리포트 숫자를 시트와 맞추려면 필요해서 MVP로 올림)
7. **설정**: 대분류·소분류, 지출방법, 태그 관리 (추가·수정·숨김·순서 변경)
8. **시트 가져오기**: 참고 시트 xlsx를 올리면 설정·거래·예산·목표·이벤트·예비비를 한 번에 가져옴 ([8장](#8-시트-가져오기)). 전체 데이터 xlsx/CSV 내보내기
9. **가구 공유 (부부 2인)**: 초대 링크로 배우자 추가, 거래마다 입력자 기록
10. **로그인**: 구글, 카카오 (이메일 로그인은 2차)

### 2차
- **이메일 로그인**
- **결제일 관리 → 반복 거래**: 내용·구분·금액·결제일·결제수단을 등록하면 매월 결제일에 거래를 만들거나 확인 요청
- **자산관리**: 부채·비유동자산·유동자산 항목을 월별로 기록, 순자산 추이 차트
- **대출·카드·통장 관리** 목록. 카드의 월 예산·결제일은 대시보드와 연결
- PWA (홈 화면 추가, 오프라인 입력 후 동기화)

### 3차 (검토)
- 영수증 사진 첨부
- 카드 결제 문자·알림 붙여넣기로 자동 입력
- 태그·소분류 기준 과소비 알림

## 5. 화면 구성 (IA)

```
/                     이달의 정리 (월 대시보드)
/transactions         거래 내역 (리스트 | 달력) + 입력
/budget               예산·목표 (대분류 예산, 수입·저축·지출 목표, 주간별 표)
/reports/[year]       연간 리포트
/reserve              예비비
/assets               자산 (2차)
  ├─ loans            대출 관리
  ├─ cards            카드 관리
  ├─ bank-accounts    통장 관리
  └─ payments         결제일 관리
/settings
  ├─ categories       대분류·소분류
  ├─ payment-methods  지출방법
  ├─ tags             태그
  ├─ members          가구 멤버
  └─ data             가져오기 / 내보내기
```

### 주요 화면

**이달의 정리** (시트 월별시트 왼쪽 영역)
- 상단: 월 선택(◀ 2025.12 ▶, 기간 `12/1 ~ 12/31` 표시)
- 요약 카드 4개: 총 수입 / 총 지출 / 총 저축 / 저축률 (전월 대비 증감)
- 목표 달성률 바 3개: 수입·저축·지출
- 대분류별 예산 진행 바 (80% 주의, 100% 초과 색상 구분)
- 저축·지출 비중 도넛 (2% 이하는 기타)
- 무지출 달력: 비고정지출이 없는 날 색 표시, 이달의 무지출 일수
- 결제 수단별 · 태그별 합계 표
- 이달의 이벤트 목록

**거래 내역** (시트 월별시트 오른쪽 입력 표)
- 리스트: 날짜별 그룹, 일별 소계, 고정지출은 아이콘으로 구분
- 달력: 날짜 칸에 일 지출 합계
- 입력: 모바일은 하단 `+` 버튼 → 바텀시트(유형 탭 수입/저축/지출 → 대분류 → 소분류 순 칩 선택), 데스크톱은 표 상단 인라인 입력 행
- "분류 필요" 배지: 대분류·소분류가 비어 있는 가져온 거래

**연간 리포트** (시트 통합시트)
- 연간 총 수입 / 총 저축 / 총 지출(월 지출 + 예비비 지출)
- 월별 수입·저축·지출 추이 막대
- 수입·저축·지출 월별 상세표: 행 = 대분류 > 소분류, 열 = 1~12월 + 합계 + 월평균

### 기본 카테고리 (새 가구 생성 시)

참고 시트의 대분류를 바탕으로 하되, 개인 항목은 뺐다. 시트를 가져오면 시트의 카테고리가 그대로 들어간다.

| 대분류 | 종류 | 소분류 |
|---|---|---|
| 수입 | income | 월급, 부수입, 수당, 이월 |
| 저축 | saving | 적금, ISA, 연금, IRP |
| 고정지출 | fixed_expense | 주거비, 보험료, 통신비, 가스비, 관리비, 렌탈비, 교통비 |
| 식비 | variable_expense | 마트, 편의점, 외식, 배달, 카페 |
| 용돈 | variable_expense | 주유비, 톨비, 점심식대 |
| 생활용품 | variable_expense | 생필품/소모품, 수리비, 주방/욕실 |
| 의복/미용 | variable_expense | 의류, 화장품, 헤어 |
| 육아비 | variable_expense | 의류, 기저귀, 소모품, 보육료 |
| 건강 | variable_expense | 병원, 약국, 영양제 |

| 기타 | variable_expense | 자동차세, 지방세, 차수리비, 기타 |

## 7. 집계 규칙

시트 수식을 옮긴 것이다. 집계 함수는 단위 테스트로 시트 계산값과 맞춰 본다.

| 항목 | 규칙 |
|---|---|
| 월 기간 | 그 달 1일 ~ 말일 |
| 총 수입 | 기간 안, 대분류 종류 `income` 금액 합 |
| 총 저축 | 기간 안, `saving` 금액 합 |
| 총 지출 | 기간 안, `fixed_expense` + `variable_expense` 금액 합 |
| 저축률 | 총 저축 ÷ 총 수입 (수입 0이면 표시 안 함) |
| 목표 달성률 | 유형별 실적 ÷ 목표 (목표 0이면 "목표 없음") |
| 결제 수단별 | 지출 거래만, 지출방법별 합 |
| 태그별 | 모든 유형, 태그별 합 |
| 무지출 Day | 기간 안에서 `variable_expense` 거래가 없는 날 |
| 주간 구분 | 월요일 시작 달력 주. 기간의 첫 주 = 1주차, 최대 6주차 |
| 지출 비중 차트 | 저축·지출 대분류별 금액 ÷ (총 지출 + 총 저축). 2% 이하는 `기타`로 합침 |
| 연간 월평균 | 연간 합 ÷ 경과한 월 수 (연도가 끝나면 12) |
| 연간 총 지출 | 월 지출 합 + 예비비 지출 합 (시트와 동일). 월 대시보드 총 지출에는 예비비를 넣지 않음 |
| 예비비 분류별 | 입금 = 해당 분류 입금 내역 합, 지출 = 연간 기간 안 해당 분류 지출 합, 잔액 = 입금 − 지출 (음수면 0, 시트와 동일) |
| 예비비 총계 | 총 입금 / 총 지출 / 총 잔액 = 분류별 합 |
| 순자산 | (비유동자산 + 유동자산) − 부채, 월별 |

## 8. 시트 가져오기

참고 시트 구조 전용 xlsx 가져오기를 만든다. 브라우저에서 SheetJS로 읽고, 미리보기에서 확인한 뒤 저장한다.

| 시트 위치 | 가져올 곳 |
|---|---|
| `설정` C3 · E3 · G3 | 가계부 시작 연·월·일. 월별시트 N번 = 시작 월 + (N−1). 시작일이 1일이 아니면 가져오기 전에 경고 |
| `설정` B6:B29 / C6:Q29 | 대분류 / 소분류. 종류는 이름으로 정함 (`수입`→income, `저축`→saving, `고정지출`→fixed_expense, 나머지→variable_expense) |
| `설정` C2:L2 | 지출방법 |
| 월별시트 E15:E24 | 태그 |
| 월별시트 T:Z 7~26행, 30~329행 | 거래 (날짜·내용·금액·대분류·소분류·지출방법·태그) |
| 월별시트 C 열 대분류 블록 (57·70·77…행) | 대분류별 예산 |
| 월별시트 C37 · C44 · C50 | 수입·저축·지출 목표 |
| 월별시트 H16:J | 이달의 이벤트 |
| `예비비` B10:C21, B26:E, K10:O | 예비비 분류, 입금 내역, 지출 내역 |
| `자산관리` D11:P38 | 자산 항목과 월별 금액 (2차) |
| `대출 관리` · `카드 관리` · `통장관리` · `결제일 관리` 4행부터 | 각 목록 (2차) |

**가져오기 규칙**
- 날짜·금액이 없는 행은 건너뛴다.
- 대분류·소분류가 없는 행은 미분류로 저장하고 "분류 필요" 목록에 올린다. 시트에서는 집계에서 빠지던 건이다.
- **분류 스크립트**: 미분류 건(2025년 10월 46건 포함)은 사용자가 제공하는 분류 스크립트로 채운다. 스크립트를 받으면 입력·출력 형식을 확인해 가져오기 뒤 단계(또는 별도 실행 명령)로 연결한다. 스크립트가 분류하지 못한 건은 "분류 필요" 목록에 남긴다.
- 설정에 없는 소분류·지출방법·태그가 나오면 자동으로 추가하고 미리보기에 표시한다.
- 같은 파일을 다시 올리면 이전 가져오기 배치를 지우고 새로 넣을지 묻는다.
- 원본 xlsx 파일은 서버에 저장하지 않는다.

## 9. 기술 스택 (제안)

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | 화면·API를 한 저장소에서 관리, Vercel 배포가 간단함 |
| UI | Tailwind CSS + shadcn/ui | 모바일 바텀시트·칩 선택·표를 빠르게 구성 |
| DB·인증 | Supabase (PostgreSQL + Auth) | 구글·카카오 OAuth 기본 지원(이메일도 같은 방식으로 추가), Row Level Security로 가구 단위 데이터 격리 |
| 집계 | PostgreSQL 뷰/함수 + TypeScript 순수 함수 | 기간·주차 계산은 TS 함수로 두고 테스트 |
| 차트 | Recharts | 도넛·막대·추이 차트 |
| xlsx | SheetJS | 브라우저에서 시트 읽기, 내보내기 |
| 폼·검증 | React Hook Form + Zod | 입력 폼과 가져오기 검증 스키마 공유 |
| 배포 | Vercel + Supabase 무료 플랜 | 가족 규모 사용량은 무료 범위 안 |
| 테스트 | Vitest (집계·가져오기), Playwright (입력 흐름) | 참고 시트 계산값을 기대값으로 사용 |

**보안**
- 모든 테이블에 `household_id` 기준 RLS를 적용해, 본인이 속한 가구 데이터만 읽고 쓰게 한다.
- 계좌번호는 끝 4자리만 저장한다.
- 참고 시트 원본은 저장소에 커밋하지 않는다 (개인 금융 정보).
